Description

A single source within the OT/PCN segment sends probe packets targeting industrial protocol ports. This rule detects two attack patterns: horizontal scans (one port, many IPs) and vertical scans (one IP, many ports) — as well as combined hybrid patterns.

Three evasion variants are covered: slow scan distributed over time, time-window boundary evasion, and hybrid scanning with mixed destinations and ports. The ScanType column in the output classifies each alert automatically.

A 10-minute sliding window captures all patterns in a single SPL query. The response and analysis logic is identical for both scan types — only the classification label differs.

Splunk Query — Horizontal & Vertical Scan Detection (Network Logs)

index=network sourcetype=network_logs
    dest_port IN (102, 502, 2222, 2404, 4840, 4843, 9600,
                  1911, 4911, 26000, 44818, 48898, 34980)
| streamstats time_window=10m
    dc(dest_ip)        AS Destinations
    dc(dest_port)      AS Ports
    values(dest_ip)   AS DiscoveredHosts
    values(dest_port) AS DiscoveredPorts
    values(action)    AS Action
    BY src_ip
| where Destinations >= 3 OR Ports >= 3
| eval ScanType = case(
    Destinations >= 3 AND Ports >= 2, "HORIZONTAL + VERTICAL",
    Destinations >= 3,                 "HORIZONTAL",
    Ports         >= 3,                 "VERTICAL")
| eval Severity = case(
    Destinations >= 3 AND Ports >= 2, "HIGH",
    Ports         >= 4,                 "HIGH",
    true(),                             "MEDIUM")
| table src_ip, Destinations, Ports, DiscoveredHosts, DiscoveredPorts, Action, ScanType, Severity
HORIZONTAL 1 port → many IPs
VERTICAL 1 IP → many ports
HORIZONTAL + VERTICAL many IPs → many ports
